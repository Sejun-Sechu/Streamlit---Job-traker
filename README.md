# Spring Week Job Tracker

A simple Streamlit application for tracking Spring Week and internship applications.

## Features

- Add a company, role, application link, deadline, and status
- Validate required inputs
- Save application data locally in a CSV file
- View saved applications in a table
- Delete an application

## Built With

- Python
- Streamlit
- CSV

## Run Locally

```bash
python -m pip install streamlit
python -m streamlit run main.py
```
